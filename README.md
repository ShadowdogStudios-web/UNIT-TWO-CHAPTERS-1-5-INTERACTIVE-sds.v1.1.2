# Promise & Practice — Unit Two, Chapters 1–5 (narrated, all in one)

One self-contained page. A top menu switches between the five narrated chapters;
each plays its narration offline once loaded.

## Deploy
1. Create a new repository (e.g. `pp-u2-chapters`).
2. Add file → Upload files → drag in **index.html** (and .nojekyll if visible). Commit.
3. Settings → Pages → Branch `main`, folder `/ (root)` → Save.
4. Live at https://shadowdogstudios-web.github.io/pp-u2-chapters/

Audio and images were lightly compressed so the five chapters fit in one ~22 MB file
(under GitHub's web-upload limit). Single-page site: .nojekyll is included but not required.
